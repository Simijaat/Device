# Local Development

## Prerequisites
- Node.js (v18+)
- Android Studio / Android SDK
- Java 17

## Setup
1. **Backend**: `cd backend && npm install && npm run dev`
2. **Web**: `cd web && npm install && npm run dev`
3. **Android**: Open the `/android` directory in Android Studio. Wait for Gradle sync, then hit Run.

## Environment Variables
See `backend/.env.example` and `web/.env.example`.
